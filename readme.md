# Meu Miau Pet Shop
Landing page de um pet shop fictício, desenvolvida para o desafio extra do curso de Introdução à Programação Front-End e Back-End do programa SCTEC.

A proposta do desafio era criar um página de apresentação comercial, com informações sobre o pet shop, seus serviços e formas de contato.


## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Recursos da página
- Apresentação do pet shop e seus serviços.
- Menu de navegação com versão mobile.
- Formulário de contato demonstrativo.

O formulário exibe uma mensagem de confirmação, mas não há envio de dados para um serviço de atendimento. Os links das redes sociais são ilustrativos e ainda não possuem destino configurado.
